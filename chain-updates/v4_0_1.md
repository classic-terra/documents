**Release Date**: 27 Apr 2026  </br>

## Key Changes
Release: https://github.com/classic-terra/core/releases/tag/v4.0.1

This document describes the changes introduced in **v4.0.1 relative to v4.0.0**.

For the full SDK 0.53 upgrade notes, LCD/API compatibility changes, and broader background, please refer to:
https://github.com/classic-terra/documents/blob/main/chain-updates/v4_0_0.md

### Legacy query fixes
This release includes fixes for legacy query behavior around pre-migration archive heights.

Included improvements:
- fix for **historical info queries** at legacy heights
- fix for **legacy staking queries** and validator delegation fallback behavior at pre-migration heights
- pagination / compatibility improvements for affected legacy query paths

These changes are intended to improve archive query reliability and restore expected behavior for integrations querying older chain state.

### Wasm / IBC handling update
This release updates Terra Classic's custom wasm message handling to align more closely with upstream behavior and fixes missing raw IBC wasm packet handling registration.

Included improvements:
- fix IBC handling in wasm
- register missing raw IBC wasm packet handling
- remove outdated fork-specific handling in favor of upstream-compatible behavior where appropriate

### Swagger / API documentation updates
This release also includes follow-up API / documentation housekeeping related to the v4.0.0 line, including Swagger updates where required.

## Implications / Required Actions
